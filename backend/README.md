# AMDAVAD OVEN API

A Node.js + Express + PostgreSQL service for the AMDAVAD OVEN storefront.

## What it does
- Persistent product catalogue and availability.
- Server-side order creation, price calculation and custom-pizza validation.
- Idempotency-key protection against duplicate order submissions.
- Public order tracking token without exposing customer address or phone.
- Persistent customer support tickets.
- First-owner bootstrap using a Render-generated secret, bcrypt password hash and JWT sessions.
- Role-aware staff access (owner, manager, kitchen and support).
- Kitchen order-status workflow and audit log.
- Product price/availability controls.

## Deploy on Render
This service is defined in the repository's root `render.yaml`. It runs as a free Node web service in Singapore and connects to the existing Render Postgres database through a private connection string.

Environment variables are provided by the Blueprint:
- `DATABASE_URL` (from Render Postgres)
- `JWT_SECRET` (generated by Render)
- `BOOTSTRAP_KEY` (generated by Render; use once to create the first owner)
- `FRONTEND_ORIGIN` (the static storefront URL)
- `PROMOTIONS_ENABLED=false` (demo promotions stay disabled until approved)

Health check: `/healthz`.

## Initial owner setup
1. Open the API service in Render and reveal/copy the value of `BOOTSTRAP_KEY` in its Environment page.
2. Open `https://amdavad-oven.onrender.com/admin.html`.
3. Use the one-time owner setup form with the setup key, your email and a strong password of at least 12 characters.
4. Sign in. The bootstrap endpoint is permanently disabled after the first admin user is created.
5. Keep the setup key private. You do not need to share it in chat.

- `POST /api/support`

- `POST /api/admin/login`
- `GET /api/admin/me`

- `PATCH /api/admin/products/:id`
- `GET /api/admin/support`
- `PATCH /api/admin/support/:ticketCode`

## Important payment boundary
This service does not integrate a payment provider. Every new order is initially recorded as unpaid, and there is no API to mark a payment as paid. UPI is a manual preference only. Do not accept prepaid orders or claim payment verification from this API.

## Free-tier warning
Render's free web services sleep after 15 minutes idle. Render's free Postgres has 1 GB capacity, no backups and expires 30 days after creation. This test database expires on 19 December 2026. Export and migrate it to a durable database before then and before using this for live customer orders.

## Marketing and store configuration
- `GET /api/storefront-config` publishes only the public store configuration.
- `PATCH /api/admin/settings` updates verified public store details for owner/manager roles.
- `POST /api/marketing/events` accepts anonymous, opt-in page/share/cart/referral events.
- `GET /api/admin/marketing` returns 30-day aggregate first-party campaign metrics.
- Order referral codes are stored with order request records.
- No third-party website visitor data is collected or imported.
